Equations used

T2s = T1 * (P2/P1)^((k-1)/k) (T in K)eta_s = (T2s - T1) / (T2 - T1)(n-1)/n = ln(T2/T1) / ln(P2/P1)eta_p = ((k-1)/k) / ((n-1)/n)W [kW] = m [kg/s] * Cp * (T2 - T1)

Assumptions and limits

  • Ideal-gas estimate with constant k; best for trending one machine over time, not for guarantee or ASME PTC-10 tests.
  • Use absolute pressures and stable, representative readings (same k each time when trending).
  • Shaft power is gas power only (no mechanical or seal losses).
  • Trend log is stored only in this browser (localStorage).
