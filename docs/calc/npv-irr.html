Equations used

NPV = sum_t CF_t / (1 + r)^t , t = 0..NIRR: r such that NPV(r) = 0, found by bisection on -99% to 1000%Simple payback: first t where cumulative CF >= 0, interpolated within the yearDiscounted payback: same on cumulative discounted CF

Assumptions and limits

  • Year 0 cash flow is undiscounted (normally the investment, negative).
  • Cash flows occur at year end; constant discount rate.
  • If cash flows change sign more than once there can be several IRRs; a warning is shown and the lowest root found is reported.
  • Any currency; nominal or real basis must match the discount rate.
