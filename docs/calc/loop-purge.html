Equations used

Purge P = F * y_feed / y_loopRecycle ratio = Recycle / FSingle-pass conversion = (n_in - n_out) / n_inOverall conversion = 1 - P*(1 - y_loop) / (F*(1 - y_feed))

Assumptions and limits

  • Steady state; inerts (CH4, N2, Ar) leave only with the purge (dissolved gas in crude methanol neglected).
  • Purge has loop composition; non-inert purge gas is counted as lost reactants.
  • Reactive moles = H2 + CO + CO2 on a consistent basis.
